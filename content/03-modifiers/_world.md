Edit Mode changes a mesh for good. A **modifier** changes how a mesh *looks and behaves* without touching
the original vertices. It sits in a stack on the object, you can reorder it, switch it off, change one
number and watch the model update, or throw it away.

That is **non-destructive modelling**, and it is the difference between "I have to start over" and "let me
change one number". Professionals work this way because the second version of any design is never the
final one.

In this world you learn the modifiers that carry most real models (Subdivision, Mirror, Array, Bevel,
Solidify, Boolean, Screw) and then spend them on the project's hero prop: **the lantern** that will glow
in the final render.
