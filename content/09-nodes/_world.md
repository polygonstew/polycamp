Up to now you placed things by hand. A professional also builds **systems**: rules that place a thousand blades of grass, shape terrain, or rearrange a scene with one setting. This world has the three tools that
make that possible.

**Geometry Nodes** is a node editor for *geometry*: the same node-and-wire ideas as materials, but the nodes create, move and instance meshes. It is what Blender artists use to scatter, array, grow and deform
things procedurally without destroying the original model.

**Pipeline habits** are the unglamorous side of professional work: naming, organising, cleaning up, and keeping a file safe. They are what makes a project survive a second week.

**Python** is how every solution script in this course works. You will read a bit of it, run a bit of it and write a bit of it. You do not need to become a programmer to benefit, but one loop will save you an afternoon.
